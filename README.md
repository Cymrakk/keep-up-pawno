# Keep! Up! Pawno!

[![Latest Version](https://img.shields.io/github/v/release/Cymrakk/keep-up-pawno?include_prereleases&display_name=tag)](https://github.com/Cymrakk/keep-up-pawno/releases)

Keep! Up! Pawno! is a lightweight and fast C++ IDE for SA-MP and open.mp. Built to replace the outdated Pawno.exe, it features a visual dialog designer and instant portable execution. Thanks for checking it out! :)

# 🚀 How to Build the Program

Follow these simple steps to set up and build the project on your Windows machine.

> 💡 **Prerequisite:** Make sure you have [Git](https://git-scm.com) installed on your system.

### 🛠️ Step-by-Step Guide
1. **Clone or download** this repository:
   ```bash
   git clone https://github.com/Cymrakk/keep-up-pawno
   ```

2. **Navigate** to the `utils` folder:
   ```cmd
   cd utils
   ```

3. **Run the setup script** to automatically download all necessary files and dependencies to build the project:
   ```cmd
   setup_workspace.bat
   ```

4. **Return to the root directory** of the project:
   ```cmd
   cd ..
   ```

5. **Run the build script** to compile the program:
   ```cmd
   build.bat
   ```

---
> 📂 **Note:** Once the build process finishes, you will find your compiled files inside the `main\build` folder.

> ⚠️ **Windows Note:** If the script fails to run, try opening your Command Prompt (CMD) or PowerShell as an Administrator.
